# README visual system

Original SVG graphics for PRAN RAKSHAK's Vishwakarma Awards 2026–27 Stage 2 README. Section flow, compact badges, three-column problem cards, captioned visuals, and roadmap take structural inspiration from [dmunish/reach](https://github.com/dmunish/reach#readme). Its text, imagery, icons, and project claims are not copied.

The [updated submission](../../docs/stage-2-submission-updated.pdf), especially pages 2–7, supplies the identity, helmet concept, monitoring gaps, and architecture. The helmet illustration is conceptual. Evidence-strip figures come from the repository's schematic review and numerical study.

- `hero.svg`: connected helmet, project identity, event, and team.
- `badges.svg`: stage, proposed stack, and native file availability.
- `architecture.svg`: proposed sensing, network, and offline supervision.
- `evidence-strip.svg`: schematic and simulation counts with limitations.
- Ten line icons: section markers and problem-card illustrations.

Palette: navy `#0b1728`, teal `#55dacb`, safety amber `#f4c66a`, off-white `#f2f7fc`. Graphics use system fonts, SVG titles/descriptions, and no scripts, remote resources, or animations. Decorative icons have empty alt text in the README; larger graphics have descriptive alt text and adjacent prose.

## Rebuild

Run `python assets/readme/generate.py` from the repository root using Python 3. It uses only the standard library and writes 14 SVGs in this directory. Edit the generator when changing artwork to keep assets reproducible. Scientific plots remain the actual FEA outputs and are not generated by this script.
